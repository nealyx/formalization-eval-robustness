# Meaning-preserving transformations

**Status:** documentation only; no generator or proof certificates are published
here.

Possible transformations include reordering conjunctions or regrouping logically
equivalent expressions. Their validity depends on the exact expression, types
and assumptions. A future certificate should bind to the exact text evaluated,
not merely to a similar handwritten statement.

Equivalence to a candidate does not establish faithfulness to its source.
Transformations can preserve an already incorrect or incomplete formalization.
