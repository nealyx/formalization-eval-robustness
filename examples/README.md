# Examples and labels

**Status:** documentation only; no benchmark or labeled dataset is published here.

A future example should include its source statement and provenance, exact
candidate formalization, domain assumptions and independent evidence for the
faithfulness label. A concrete counterexample can establish a missing
constraint; an evaluator's own verdict cannot serve as its ground truth.

Keep faithful controls alongside unfaithful candidates. The logical example in
the [root README](../README.md#the-question-in-one-example) illustrates this
distinction without claiming an empirical result.
