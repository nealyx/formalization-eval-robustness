# Baseline evaluator

**Status:** documentation only; no evaluator implementation is published here.

A future baseline should identify its source, revision, dependencies, prompts,
model settings, response parser and aggregation rule. A deterministic offline
check should make the scoring behavior inspectable before live evaluation.

Baseline corrections belong in [patches/](../patches/README.md). Results from a
modified pipeline must identify that modification rather than being attributed
to an unchanged upstream system.
