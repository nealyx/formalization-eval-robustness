# Experiment design

**Status:** proposed design only; no runnable experiment is published here.

A useful comparison would hold the source, candidate label, evaluator and
settings fixed while varying presentation. Unchanged-input repetitions estimate
ordinary evaluator variability. Faithful controls help distinguish blanket
rejection from useful discrimination.

If a search selects promising presentations, its call budget and selection rule
should be recorded in advance, with fresh evaluations reserved for confirmation.
Report all attempted calls, invalid responses and incomplete runs. Repeated calls
on one source do not create additional independent source problems.

Implementation changes should be tested separately from representation changes.
Any eventual report should distinguish exploratory observations from a
prespecified, completed analysis.
